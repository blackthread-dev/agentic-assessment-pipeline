# Tool Research

Guardrails applied: prefer the existing stack (the owner does not want a migration), include non-AI options,
and mark anything not verified on a vendor page as **needs verification**.

> In this sample run, live vendor research was intentionally skipped, so every price and feature claim below
> is marked "needs verification". In a real engagement each row carries a source URL and the date checked.
